# 生物医药类新书智能化采选分析系统

> 面向图书馆采选业务的纯前端工具：解析 **ISO 2709 / CNMARC** 机读目录，提供候选书目与已选书目的多维统计分析、**生物医药十大出版社占比**核验，以及基于大模型（LLM）的数据问答。
>
> **单 HTML 文件 · 零依赖 · 离线可用 · 数据不出本机**

## ✨ 功能特性

- **ISO 2709 / CNMARC 解析**：GBK / UTF-8 自动识别，支持 `.iso` / `.mrc`；字段级解析可视化查看
- **数据表格**：全文检索、逐列筛选、点击排序、列显示设置、批量勾选删除
- **导出**：勾选条目导出 CSV（UTF-8 BOM），或导出 ISO（直接回写原始记录字节，与导入文件格式逐字节一致）
- **候选书目分析**：定价 / 页码 / 实洋 KPI；中图法大类、出版社 Top 12、出版年份、主题词、语种、装帧、定价区间分布
- **十大出版社占比**：生物医药十大核心出版社图书占比饼图（候选与已选两侧均有），其余出版社合并为"其他出版社"
- **已选书目分析**：上传 xlsx / csv 选购清单，自动按书名与 ISO 数据匹配、回填中图法分类；中图法 Q / R 小类分布（内置《中国图书馆分类法》类目名称）
- **订购折扣**：全局折扣一键计算实洋（实洋 = 定价 × 折扣）
- **AI 数据问答**：接入任意 OpenAI 兼容接口（DeepSeek / 智谱 / 通义 / Kimi / OpenAI / 本地 Ollama），支持多种数据上下文粒度；AI 可通过 `<<勾选 记录号,…>>` 指令直接在表格中勾选书目，再批量导出

## 🚀 快速开始

### 方式一：本地直接使用

用较新版本的 Chrome / Edge / Firefox 打开Releases里面的 HTML 文件即可，无需安装、无需联网（AI 问答除外）。

### 方式二：经本地 HTTP 访问（支持演示参数一键载入示例数据）

```bash
python3 -m http.server 8000
# 浏览器打开（中文路径浏览器会自动编码）：
# http://127.0.0.1:8000/生物医药类新书智能化采选分析系统.html?load=samples/示例书目.iso&xls=samples/示例选购清单.csv
```

- `?load=文件名`：自动载入同目录 ISO 书目
- `?xls=文件名`：自动载入同目录 xlsx / csv 选购清单

（若启用 GitHub Pages，可在此处放置在线演示链接。）

## 📁 数据格式要求

### ISO 书目文件

- 标准 **ISO 2709** 交换格式的中文机读目录（CNMARC 字段体系），扩展名 `.iso` / `.mrc` / `.dat`
- 编码 GBK 或 UTF-8（自动识别），记录间以 CRLF 或 LF 分隔
- 常用字段（001、010、200、210、215、330、606、690 等）的详细说明见页面内 **"ISO 2709 格式说明"** 页签

### 选购清单（xlsx / csv）

必备列：**书名**、**定价**；其余列可选，系统按以下规则识别表头：

| 列内容 | 可识别的表头名称 |
| --- | --- |
| 书名 | 书名、题名 |
| 定价 | 定价（用于统计与折扣计算） |
| 实洋 | 实洋 |
| 著者 | 著者、作者、第一责任者、责任者 |
| 出版社 | 出版社、出版者 |
| 出版时间 | 出版时间、出版日期、出版年 |
| 中图法分类 | 中图法、分类号、分类 |
| 主题词 / 语种 / 装帧 | 同名表头 |

> 若先在"数据表格"载入 ISO 书目，上传选购清单时将按书名自动匹配、回填中图法分类等字段，用于 Q / R 小类统计。

## 🤖 AI 数据问答配置

1. 展开页面底部 **"🤖 AI 数据问答"** 面板
2. 选择服务商预设（DeepSeek / 智谱 / 通义 / Kimi / OpenAI / Ollama 本地）或手动填写 OpenAI 兼容接口地址、API Key、模型名称
3. 选择"随问题附带的数据上下文"粒度：
   - 统计摘要 + 相关检索 + 样本记录（默认，节省 token）
   - 统计摘要 + 当前筛选结果全部记录（消耗大量 token，附确认弹窗）
   - **统计摘要 + 全部记录 + 十大出版社占比（判断是否不低于 50%）**——直接让 AI 核验占比门槛
   - 仅统计摘要
4. 接口需兼容 OpenAI Chat Completions 协议且允许浏览器跨域（CORS）；本地 Ollama 需设置环境变量 `OLLAMA_ORIGINS=*` 后重启

示例问句：`按出版社统计数量` · `最贵的10本书` · `R7类图书有哪些` · `勾选定价低于50元的书` · `十大出版社占比是否不低于50%？如何提升？`

## 🔒 隐私与数据安全

- **所有计算均在浏览器本地完成**：书目数据不上传任何服务器，无任何遥测、统计脚本或第三方依赖
- **API Key 只保存在本机浏览器 localStorage**，不会随数据发送给本项目以外的任何方
- AI 问答是**您的浏览器直连您配置的接口**，请自行评估所选大模型服务商的数据政策
- 本仓库 `samples/` 中的示例数据均为**虚构**，不含任何真实书目

## 🧪 已知限制

- `file://` 直接打开时主功能可用，但 `?load=` / `?xls=` 演示参数受浏览器限制需经 HTTP 访问
- 解析 xlsx 需要 `DecompressionStream`（Chrome 80+ / Edge 80+ / Firefox 113+ / Safari 16.4+）
- AI 勾选为**累加式**（在现有勾选上追加，不会自动清空上一轮勾选），多轮选书后导出前请核对"已勾选 N 条"计数
- 中图法小类分布按分类号前两级数字归组（如 R459.7 → R45）；数据中出现的非标准分类号（如 R41）无法取到类目名，回退显示大类名
- "全部记录"上下文在记录数很大时消耗大量 token，已内置确认弹窗
- API Key 明文存于 localStorage，公用电脑使用后请点击"清空配置"

## 🛠 技术说明

- 纯原生 JavaScript + SVG 自绘图表，**无框架、无构建步骤、无外部 CDN 依赖**，适合内网/离线环境部署
- ISO 2709 解析器位于独立 `<script id="core">` 块，**无 DOM 依赖**，可单元测试
- xlsx 读取基于 ZIP 目录解析 + `DecompressionStream` 原生解压 + XML DOM 解析
- 页面内置"ISO 2709 格式说明"页签，含头标区/目次区/字段结构与 CNMARC 字段对照表
